# SIGA-SAP WM

Primer iteración de un sistema simple para gestión de almacén orientado a SAP WM.

## Funcionalidades

- Registro de materiales
- Registro de ubicaciones (bins)
- Recepción de stock
- Despacho de stock
- Transferencias internas
- Dashboard inicial
- Persistencia en JSON

## Cómo ejecutar

```bash
python main.app
```
